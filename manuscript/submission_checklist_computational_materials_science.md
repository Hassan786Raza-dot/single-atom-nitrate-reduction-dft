# Submission checklist: Computational Materials Science

## Article scope

The manuscript must be submitted as a reproducibility-stage computational-materials benchmark and production-readiness framework. It must not be presented as a completed 30-catalyst activity/selectivity ranking.

## Files to upload

| File | Required action | Status |
|---|---|---|
| Main manuscript | Upload the Word/PDF review file with embedded tables, figure, and equations | Prepared |
| Highlights | Upload or paste the five prepared highlights | Prepared |
| Graphical abstract | Upload only a workflow graphic that does not imply unsupported catalyst performance | Specification prepared; graphic remains optional and must be author-approved |
| Supporting Information | Upload as a separate supplementary file | Prepared in Word source; convert if portal requires PDF |
| Cover letter | Address the editor and name the journal | Prepared |
| Research-data statement | Include the public repository and explain VASP licensing boundaries | Prepared |
| Clean source archive | Retain Markdown, scripts, data, and environment files | Prepared in GitHub repository |

## Author declarations to complete

The corresponding author must complete the actual author list, affiliations, ORCID identifiers, contribution statement, funding statement, competing-interests declaration, institutional approval, and confirmation that the manuscript is not under consideration elsewhere. These cannot be completed accurately by an automated package because they depend on author information.

## Scientific checks before upload

Confirm that the title, abstract, highlights, cover letter, conclusions, tables, figure captions, and metadata all describe the work as a benchmark. Confirm that no diagnostic-only calculation is labelled as accepted. Confirm that all repository URLs work from a clean checkout. Confirm that all files and figures are owned by the authors or appropriately licensed.

## Important acceptance statement

Peer review and editorial assessment determine acceptance. No journal can guarantee acceptance. The present package is suitable only for consideration under the benchmark framing; a high-impact catalyst-discovery claim requires additional accepted production DFT calculations.
