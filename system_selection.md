# System Selection

## Supports

The primary comparison uses three model supports: nitrogenated graphene with a four-coordinate defect site, 2H-MoS₂ with a defined sulphur-vacancy anchoring environment, and a g-C₃N₄ sheet with a reproducible in-plane coordination site. These are selected to span conductive carbon, a semiconducting transition-metal dichalcogenide, and a polar nitrogen-rich framework. The anchoring motifs are model definitions and must not be conflated with a universal experimental structure.

## Metals

The initial metal set is Fe, Co, Ni, Cu, Zn, Ru, Rh, Pd, Pt, and Au. Fe, Co, and Ni provide first-row non-precious candidates with multiple accessible spin states; Cu and Zn probe late first-row chemistry and weaker or closed-shell binding; Ru, Rh, Pd, and Pt provide noble or platinum-group reference chemistry; Au provides a weak-binding, late-metal boundary case. The set deliberately balances activity hypotheses, cost, stability, and experimental relevance.

| Category | Metals | Rationale |
|---|---|---|
| Earth-abundant first row | Fe, Co, Ni, Cu, Zn | Cost-sensitive screening and diverse spin/electronic structure |
| Platinum-group | Ru, Rh, Pd, Pt | Mechanistic and adsorption reference points, with a cost penalty |
| Late noble-metal boundary | Au | Weak-binding/selectivity boundary and stability reference |

## Design controls

Each support must use the same supercell family, vacuum spacing, electronic convergence criterion, spin-state enumeration rule, adsorbate orientation search, and thermochemical convention. Defect formation energies and metal binding energies must be reported separately for each support. A ranking is not valid if one support is modelled with a cluster and another with a periodic slab.

## Planned matrix

The nominal matrix contains 30 SAC models before spin, adsorption, solvation, and configuration refinement. A staged screen should first optimise bare supports and anchored metals, then test nitrate, H*, and selected nitrogen intermediates. Full pathway and transition-state calculations should be reserved for the top candidates and representative failure cases.
